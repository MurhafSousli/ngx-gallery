# Autoplay

Enables automatic slide progression through gallery items.

### Behavior

* Slides advance only after the current item finishes loading.
* Playback pauses on user interactions based on `autoplayPause` settings or active scrolling.

### Quick Start

```html
<gallery autoplay [items]="items" />
```

### Full Example

```html
<gallery [items]="items"
         [autoplay]="autoplay"
         autoplayPause="hover"
         autoplayInterval="2500"
         autoplayDirection="ping-pong"
         autoplayScrollBehavior="auto"
         (autoplayChange)="onAutoplayChange($event)">
  <img *galleryItemDef="let item" galleryImage [src]="item.src" [alt]="item.alt"/>
</gallery>

<button (click)="autoplay = true">Play</button>
<button (click)="autoplay = false">Stop</button>
```
