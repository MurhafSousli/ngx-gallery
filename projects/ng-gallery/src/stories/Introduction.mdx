A flexible and extensible gallery library for Angular applications.

It provides a solid foundation for building sliders, and media viewers with high performance, reliability, and full design control.


## Technical Overview

`ng-gallery` is a modular, template-driven gallery designed for modern Angular (Signals-first, zoneless compatible).

### Key Characteristics

  - Extensible architecture — features can be composed and expanded without modifying core behavior
  - High performance — built on native scrolling and reactive Signals
  - Deterministic state management — clear separation between live and stable navigation state
  - Template-driven rendering — structural directives define slides and UI elements explicitly
  - Well-tested interaction model — reliable handling of dragging, scrolling, and idle states

### Design Principles

  - Native scroll-based behavior for accessibility and performance
  - Reactive internal state using Angular Signals
  - Modular directives for observation, navigation, and layout control
  - Clear separation between presentation and state logic
