# Layout Configuration

Use `itemSize` or `itemsPerView` to control how the gallery is arranged.

`itemSize` is the preferred option when you want to define the size of each item directly.
If `itemSize` is set, `itemsPerView` is ignored.

Use `itemsPerView` when you want the gallery to show a specific number of items at once.
When `itemSize` is not set, the gallery falls back to `itemsPerView`, which defaults to `1`.

The `gap` input can be used to add spacing between items.
