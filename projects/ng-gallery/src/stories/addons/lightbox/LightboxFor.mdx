# LightboxFor directive

Alternatively you can use the `lightboxFor` directive to open the lightbox programmatically.

```html
<ng-template lightbox #lightbox="lightbox">
  <gallery [items]="items">
    <img *galleryItemDef="let item" galleryImage [src]="item.src" [alt]="item.alt"/>
  </gallery>
</ng-template>

<button [lightboxFor]="lightbox" [lightboxIndex]="initialIndex">Open Lightbox</button>
```
